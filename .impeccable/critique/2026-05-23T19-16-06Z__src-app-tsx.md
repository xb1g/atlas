### Priority Issues

#### [P1] Invalid Tailwind CSS Classes & Broken Colors
- **What**: Multiple components contain hallucinated Tailwind classes (e.g., `bg-emerald-555/10`, `text-emerald-855`, `border-emerald-205/50`, `text-amber-805`, `text-slate-705`, `border-orange-140`, and `border-orange-150/40`).
- **Why it matters**: These classes do not exist in Tailwind's parser. They fall back to transparent backgrounds, invisible icons, and missing borders, spoiling the custom Monet palette and destroying container boundaries.
- **Fix**: Map all hallucinated classes to standard Tailwind shades. Unify borders using variables or standard classes (e.g. `border-orange-100` or `border-emerald-100`) to guarantee high-fidelity rendering.
- **Suggested command**: `/impeccable polish src/App.tsx`

#### [P1] Touch Target Accessibility Violation (Age Selector)
- **What**: Interactive age selection buttons are sized to `w-10 h-10` (40px by 40px).
- **Why it matters**: Both WCAG guidelines and the target design code in `DESIGN.md` require touch targets to be at least `44px` (preferably 48px) to accommodate kid/teen hand motor coordination and prevent frustrating mis-taps.
- **Fix**: Elevate age selection buttons to at least `w-11 h-11` (44px) or `w-12 h-12` (48px) so they are physically responsive and comfortable for touch.
- **Suggested command**: `/impeccable adapt src/components/InterviewForm.tsx`

#### [P2] Visual Contrast of Small Micro-Helptext
- **What**: Micro-help captions contain light green opacity blends like `text-[10px] text-emerald-800/60 italic` on paper canvas blocks.
- **Why it matters**: The contrast of 60% opacity green against off-white warm parchment (#f7f5ee) is extremely low, making essential instructions unreadable for kids with moderate visual impairment, or under direct mobile sunlight.
- **Fix**: Force text opacity to at least `85%` (e.g., Change `text-emerald-800/60` to `text-emerald-905/90` or `text-emerald-900`) and raise the tiny 10px text size to `11px` (`text-[11px]`).
- **Suggested command**: `/impeccable layout src/components/InterviewForm.tsx`

#### [P2] Navigation Header Layout Consistency
- **What**: Header container uses raw margin alignments that mismatch the broad canvas grids.
- **Why it matters**: The persistent App Header frames the entire child experience, so minor spacing discrepancies block the prestigious feeling.
- **Fix**: Re-align margins and use more intentional, soft parchment shadows.
- **Suggested command**: `/impeccable layout src/App.tsx`

### Persona Red Flags

#### **Sam (Young Activist - Age 13)**
- **Sam's Goal**: Wants to build an action page for beach cleanup but gets easily overwhelmed by small words.
- **Red Flags Found**: The tiny `10px help text` in `InterviewForm` under the spark field causes eye fatigue. The compact interactive option buttons are tiny on his smartphone, causing Sam to mis-tap "Websites" as "Ecology Maps" by mistake. Sam feels confused and abandons the wizard.

#### **Maya (Idealistic Teen - Age 16)**
- **Maya's Goal**: Selects a blog topic easily but wants to see clear navigation controls.
- **Red Flags Found**: On entering the Opportunity Menu, the back button is styled identically to "Practice Lab" badges and uses a small, generic text string with low contrast. She misses the visual hierarchy and is unsure how to return to edit her name.
